public(誰からもアクセス可)static(クラス名で直接呼び出せる)

アクセス修飾子
    public
        もっとも公開範囲が広い。外部からのアクセスも可能で外部からのアクセスを前提としている。
        1つのファイルが複数のクラスが複数のクラスを持つことは可能だが、publicクラスはファイル名と同名のクラスでなくてはならないため、1ファイルにつき1クラスしか保持できない。

    private
        もっとも公開範囲が狭い。外部からのアクセスは不可、最も変更に強くすべてを公開しない。
        privateのメソッドやフィールドが変数や引数を持つ場合は、同じクラス内で行うことを前提としている。

    protected
        公開範囲が「同じクラス内」「同じパッケージ内」「継承したサブクラス」となり、外部パッケージのアクセスを許可しない。
        「継承したサブクラス」が外部パッケージにある場合はそのクラスのみアクセスを許可する。
